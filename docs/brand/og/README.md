# ภาพแชร์ลิงก์ (Open Graph)

`og.png` คือภาพที่โผล่ขึ้นมาตอนมีคนแชร์ลิงก์เว็บใน LINE, Facebook, X, Discord
ขนาดมาตรฐานคือ **1200 × 630 พิกเซล**

**สถานะ: ยังไม่ได้ใช้งานจริง** — `public/og.png` ในเว็บยังเป็นไฟล์เดิม
การเปลี่ยนเป็นงานเฟส 2 ที่รออนุมัติ

---

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
|------|---------|
| `og.svg` | **ต้นฉบับ** — แก้ข้อความหรือสีที่นี่ |
| `og.png` | ไฟล์ที่เอาไปใช้จริง สร้างจาก `og.svg` |
| `render-og.py` | สคริปต์แปลง `og.svg` เป็น `og.png` |
| `og.html` | เวอร์ชัน HTML สำหรับส่งเข้า Adobe Express (ดูหัวข้อล่างสุด) |

---

## วิธีแก้ไข

1. แก้ข้อความหรือสีใน `og.svg`
2. รันคำสั่ง:

```
pip install cairosvg fonttools brotli
python docs/brand/og/render-og.py
```

3. **เปิด `og.png` ดูด้วยตาทุกครั้ง** ว่าตัวอักษรไทยไม่กลายเป็นสี่เหลี่ยมเปล่า

---

## ทำไมต้องมีสคริปต์ ไม่แก้ PNG ตรงๆ

PNG เป็นภาพจุดสี แก้ข้อความไม่ได้ ส่วน SVG เป็นคำสั่งวาด แก้ข้อความได้
ถ้าเก็บแค่ PNG พอเปลี่ยนสโลแกนทีเดียวก็ต้องวาดใหม่ทั้งภาพ

---

## เรื่องฟอนต์ไทย — จุดที่พังง่ายที่สุด

โปรแกรมวาดภาพต้องหา**ไฟล์ฟอนต์ไทย**ในเครื่องให้เจอ ไม่งั้นตัวอักษรไทยจะกลายเป็นสี่เหลี่ยมเปล่า (□□□) ทั้งหมด

เรื่องนี้**เกิดขึ้นจริงตอนสร้างไฟล์นี้ครั้งแรก** — ภาพออกมาสวยแต่ข้อความไทยเป็นสี่เหลี่ยมทุกตัว

สาเหตุคือแพ็กเกจ `@fontsource/noto-sans-thai` ที่เว็บใช้อยู่ **แยกไฟล์ฟอนต์ตามภาษา**
(ไฟล์หนึ่งมีแต่ตัวอังกฤษ อีกไฟล์มีแต่ตัวไทย) เพื่อให้เว็บโหลดเร็ว
แต่โปรแกรมวาดภาพเลือกใช้ได้ไฟล์เดียวต่อหนึ่งชื่อฟอนต์ จึงได้ตัวอังกฤษแต่ตัวไทยหาย

`render-og.py` แก้ให้แล้วโดย**รวมสองไฟล์เข้าด้วยกัน**ก่อนติดตั้ง ตั้งชื่อวงศ์ฟอนต์ว่า `RLNotoThai`
ซึ่งเป็นชื่อที่ `og.svg` เรียกใช้ — **ถ้าเปลี่ยนชื่อนี้ ต้องแก้ทั้งสองไฟล์ให้ตรงกัน**

ข้อกำหนด: ต้องรัน `npm install` ที่รากโปรเจกต์มาก่อน เพราะสคริปต์ดึงไฟล์ฟอนต์จาก `node_modules`

---

## `og.html` คืออะไร

เนื้อหาเดียวกับ `og.svg` แต่เขียนเป็น HTML เพื่อส่งเข้า **Adobe Express** ให้แก้ไขต่อได้ด้วยมือ
(ลากย้ายตำแหน่ง เปลี่ยนข้อความ โดยไม่ต้องแตะโค้ด)

**ข้อจำกัดที่รู้แล้ว:** Adobe Fonts **ไม่มี** Noto Sans Thai (ตรวจด้วยเครื่องมือ `find_fonts` แล้ว
ได้ผลว่า `not_found` ทั้ง Noto Sans Thai และ Geist) ไฟล์นี้จึงดึงฟอนต์จาก Google Fonts แทน
ถ้าเปิดใน Express แล้วตัวอักษรไทยเพี้ยน สาเหตุคือเรื่องนี้

**ไฟล์ที่เอาไปใช้จริงคือ `og.png` ที่สร้างจาก `og.svg` เสมอ** — `og.html` เป็นแค่ทางเลือกสำหรับคนที่อยากแก้ด้วยมือ
